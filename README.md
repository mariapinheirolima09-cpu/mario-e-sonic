# mario-e-sonic
🎮 Mario vs Sonic: A Filosofia dos Pulos e Rampas (16-Bit Edition)
Este projeto é uma página web retrô inspirada na estética clássica de 8 e 16 bits dos jogos dos anos 90. Ela estabelece uma comparação imersiva entre as filosofias de game design de Super Mario (focada em precisão, controle e conforto) e Sonic The Hedgehog (focada em velocidade, inércia e reflexos).

🕹️ Recursos do Projeto
Visual Retrô Anos 90: Estilização com paleta de cores vibrantes, bordas pixeladas, simulação de scanlines CRT e elementos clássicos (Bloco '?' e Anel de Ouro) feitos inteiramente em CSS puro.

Tipografia Arcade: Integração com a fonte Press Start 2P via Google Fonts.

Narrativa Imersiva: Texto fluido e nostálgico explicando por que a física do Mario transmite uma sensação satisfatória e relaxante de domínio.

Painel Interativo: Botões no estilo arcade para alternar o foco visual entre os personagens.

Single-File Ready: Todo o código (HTML, CSS e JavaScript) está contido em um único arquivo, pronto para ser executado sem dependências de build ou servidor web.
